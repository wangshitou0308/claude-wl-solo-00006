# 水表账单接续核对页

为自行管理家庭开支、常被水费单上的**估读预收、估读后补扣、换表读数**弄糊涂的长辈做的纯前端核对工具。
所有账单、费率、照片都只保存在**本机浏览器（IndexedDB）**，计算全部在浏览器内完成，不上传任何数据。

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 http://127.0.0.1:5173/）。建议用 Chrome / Edge。
首次进入可点“先装入一份示例数据看看效果”，里面包含：正常账期 → 估读预收 → 换表 → 估读后实抄补收。

生产构建：`npm run build`，类型检查已包含在构建中。
自检：`npm run test:engine`（接续核算引擎断言）与 `npm run test:smoke`（jsdom 全页面渲染：
装示例数据、勾选、改金额后旧结论失效、撤销恢复、打印卡）。

## 它帮你核对什么

按账期录入纸单：起止日期、表号、起止读数、**实抄/估读**标记、阶梯费率、固定费用、纸单水量与应缴总额。
系统沿时间轴逐期接续核算，并标出五类问题：

- **日期重叠 / 断档**：两期日期交叠可能重复计费；
- **表号断链**：本期起读数与同表上一期止读数不衔接（倒退为红色“问题”，跳数为“注意”）；
- **读数倒退**：止读数小于起读数；
- **费率跨期**：本期阶梯单价与上一期不同（调价提示，需确认适用日期）；
- **金额 / 水量不符**：按读数与费率重算，与纸单总额（2 分钱容差）、纸单水量（0.1 m³ 容差）对照。

### 估读 → 实抄的接续算法（防重复计费的核心）

每块表维护一个“**上一实抄点基线**”（真实表读数）：

1. **估读账期**：按估读水量预收，基线不动，只累计“已估收水量”；
2. **实抄账期**：`实抄区间总量 = 本期止读数 − 基线`，再`扣除此前连续估读账期已收水量`，
   差额即本期的**补收（正）/ 退减（负）/ 不补不退（0）**，并逐行列出算式；
3. **换表**：登记旧表末读数与新表初读数。旧表拆下末读数就是旧表上待核对估读的“实抄收口点”，
   若拆表读数小于估读累计，直接在换表记录上给出“应退减多少 m³”；新表首期与初读数自动接续。

### 照纸单逐字段确认，改了就作废

- 每期有 8 个勾选项（日期、表号、起止读数、实抄/估读、费率、固定费用、账单水量、账单总额），
  对着纸单勾一项算确认一项；
- 一旦修改了任何核心数字，**旧勾选全部清空**，账期顶部出现红色“结论已失效，请重新核对”横幅；
- “历史/撤销”保留最近 100 步，可**逐步撤销误改**，也可展开查看任意一步的**原始录入快照**；
- 备注、争议标记的修改不影响勾对结论。

### 照片凭据

每期可拍照/选图保存纸单照片，仅存本机（自动压缩到长边 1600px），可点开放大；删账期时一并清理。

### 打印沟通卡

点“标记争议”或账期出现红色问题后，进入“打印沟通卡”：

- 只包含**争议账期**，不印无关记录；
- 每条列出账期、表号、纸单金额、核算金额、差额，以及完整接续算式（含补收/退减水量）；
- 底部留用户与供水公司经办签字位；可直接打印或“另存为 PDF”带去窗口沟通。

## 代码结构

```
src/
  types.ts              数据类型（账期/换表/照片/核对结论）
  lib/calc.ts           接续核算引擎：时间轴、估读基线、补收退减、阶梯计费、问题检测
  lib/db.ts             IndexedDB 封装（periods/changes/photos/history 四个对象仓）
  lib/utils.ts          id、金额格式、照片本地压缩
  lib/seed.ts           示例数据
  state/store.tsx       React Context：增删改、逐字段确认、改后失效、撤销
  components/
    PeriodCard.tsx      账期带：读数来源、用量、逐项算式、问题、勾选、照片
    MeterChangeBand.tsx 时间轴上的换表记录带
    PeriodForm.tsx      账期录入/修改（含阶梯费率编辑器，实时显示表显用量）
    ChangeForm.tsx      换表登记表单
    HistoryPanel.tsx    操作历史、撤销、原始录入回看
    PrintCard.tsx       打印沟通卡（@media print 只印卡片）
  App.tsx               页面编排：合并时间轴、汇总、筛选、弹窗
```

## 数据安全说明

数据保存在当前浏览器的 IndexedDB 中；更换电脑/浏览器、清理站点数据会丢失记录，
建议沟通处理完毕后用“打印 / 另存为 PDF”留一份纸质备份。
